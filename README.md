# Form Buddy

Build a website form testing automation app where users enter any website link to test forms. Include:
1. Two test modes: 'Fill Only' (detects and autofills fields with realistic dummy data) and 'Fill & Submit' (autofills and submits the form).
2. Visual capture: captures screenshots centered on (1) the filled form and (2) the result state (success banner, validation messages, or error).
3. Detailed test reports with both a structured checklist (fields identified, values used, submission outcome, pass/fail status) and side-by-side visual evidence, shareable via link.
4. Team and client support: user authentication, saved sites/targets, run history, and exportable reports.
